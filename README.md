🛍️ SOUQ Deutschland

SOUQ Deutschland is a multilingual marketplace connecting buyers and sellers in Germany and Morocco.

🌍 Languages

- 🇩🇪 German
- 🇲🇦 Arabic
- 🇫🇷 French
- 🇬🇧 English

✨ Features

- Browse marketplace products.
- Buy and sell products.
- Multilingual user interface.
- Designed for Germany and Morocco.
- Modern black and gold branding.
- Android application built with Flutter.

📱 Android APK

Debug and Release APK versions are built automatically using GitHub Actions.

To download:

1. Open the repository's Actions tab.
2. Select a successful build.
3. Find the Artifacts section.
4. Download the APK you need.

🛠️ Technologies

- Flutter
- Dart
- GitHub Actions
- Android
